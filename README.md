# 自动回车助手（Auto-Enter Assistant）

这个工具会在你指定的精确时刻，自动帮你按下 **回车（Enter）** 键。它非常适合用来抢有限的预约名额、秒杀抢购，或在精确的时间点发送消息——比手动操作更快、更稳。

你**不需要懂任何编程**就能使用它。只要按照下面的步骤，把每一条命令原样复制粘贴进去即可。

---

## 第一部分：安装设置（只需做一次）

这一部分只在你第一次使用时操作一次。完成之后，以后每次使用都直接跳到**第二部分**即可。

### 第 1 步 —— 打开「终端」(Terminal)
在 Mac 上按下 `Command (⌘) + 空格`，输入 **Terminal**（终端），然后按 **回车**。会弹出一个带文字光标的窗口，你就在这里输入命令。

### 第 2 步 —— 进入工具所在的文件夹
复制下面这行，粘贴到终端里，然后按 **回车**：

```bash
cd ~/QiangChe
```

> 💡 `cd` 的意思是「进入这个文件夹」。如果你把文件夹存在了别的位置，请把 `~/QiangChe` 换成你实际存放的位置。

### 第 3 步 —— 创建一个独立的工作环境
这样可以让工具的文件和你电脑里的其他东西分开，互不影响。粘贴后按 **回车**：

```bash
python3 -m venv .venv
```

### 第 4 步 —— 启用这个工作环境
粘贴后按 **回车**：

```bash
source .venv/bin/activate
```

### 第 5 步 —— 安装工具需要的唯一一个组件
粘贴后按 **回车**：

```bash
pip3 install pyautogui
```

✅ 安装设置完成。第一部分以后再也不用重复了。

---

## 第二部分：使用工具（每次都这样做）

### 第 1 步 —— 打开终端并进入文件夹
打开终端（见第一部分第 1 步），然后粘贴下面两行，每行后面都按一次 **回车**：

```bash
cd ~/QiangChe
source .venv/bin/activate
```

### 第 2 步 —— 运行工具
根据你的需要，从下面的方式中选一种。

#### 方式 A —— 在下一个整分钟触发（最简单）
工具会等到下一个整分钟（比如 `3:24:00`），然后按下回车。它总是会给你留至少 5 秒的准备时间。如果下一个整分钟太近了（只剩 5 秒或更少），它会自动改为等待再下一个整分钟。

```bash
./auto_enter.py -n
```

#### 方式 B —— 在你指定的精确时间触发
把 `18:00:00` 换成你的目标时间，使用 24 小时制（`18:00:00` 表示下午 6:00:00）：

```bash
./auto_enter.py -t 18:00:00
```

你也可以精确到毫秒：

```bash
./auto_enter.py -t 18:00:00.500
```

运行之后，**把鼠标点进你希望按下回车的那个框里**（比如消息输入框或「确认」按钮），然后等待即可。工具会显示倒计时，并在到点时帮你按下回车。

## 调整触发时机（可选）

有时候你会希望回车**提前一点点**触发，用来抵消网络或网页的延迟。这个「提前量」用毫秒来计算（1000 毫秒 = 1 秒）。

### 快捷预设：`--home` 和 `--work`
工具内置了两个现成的提前量设置，这样你就不用去记具体数字：

- `--home` → 提前 100 毫秒（默认值）
- `--work` → 提前 100 毫秒（默认值）

在命令里加上对应的词即可使用：

```bash
./auto_enter.py -n --home
./auto_enter.py -t 18:00:00 --work
```

### 修改某个预设的数值
如果你想让 `home` 或 `work` 使用不同的提前量，设置一次就会被记住：

```bash
./auto_enter.py set home 170
./auto_enter.py set work 190
```

### 为单次运行手动设置提前量
用 `-l` 后面跟毫秒数。它只对这一次运行生效，并会覆盖预设：

```bash
./auto_enter.py -t 18:00:00 -l 80
```

> 💡 这些可以混着用：`-n`（下一分钟）、预设（`--home` / `--work`）和 `-l` 可以同时使用。

## 用完之后

要关闭这个独立工作环境，粘贴后按 **回车**：

```bash
deactivate
```

然后就可以关掉终端窗口了。

## 如果什么都没发生（Mac 权限问题）

第一次使用时，macOS 可能出于安全考虑，阻止工具帮你按键。如果倒计时结束了但回车没有被按下：

1. 打开 **系统设置 → 隐私与安全性 → 辅助功能**。
2. 把 **终端（Terminal）**（或你用来运行工具的那个应用）旁边的开关**打开**。
3. 再试一次。

### 微信 RTT 自动补偿（macOS）

打开微信并保持联网。在 Mac 应用中勾选「微信 RTT 自动补偿」后开始定时，或在终端运行：

```bash
./auto_enter.py -n --wechat-rtt
```

#### 从终端定向发送给微信

先打开 Mac 微信，在目标会话中写好消息。以下命令以当天 19:00 为目标，用平均 RTT 计算提前量，并将回车定向投递给微信。启动后点进输入框，保留当前会话直到触发。脚本可以提前半小时启动，采样仍在临近目标时进行。

```bash
./auto_enter.py -t 19:00:00 --target-wechat --wechat-rtt --rtt-stat avg
```

要练习下一个整分钟，将 `-t 19:00:00` 换成 `-n`。首次使用可加 `--dry-run` 查看计划触发时间。实际投递依赖运行脚本的终端获得辅助功能权限。

#### 提前量和日志怎么读

- **网络采样**。目标前约 10 秒，脚本每秒用 `nettop` 读取微信已建立的非回环 TCP 连接。日志显示最低、最高和平均 RTT。平均值先在每一轮内对连接取平均，再对有效轮次取平均。空闲连接可能连续多轮报告同一数值。
- **自动提前量**。默认使用最低 RTT，`--rtt-stat avg` 使用平均 RTT。选定的 RTT 除以四向下取整，再扣 5 毫秒，最低为零。无有效采样时退出；少于三轮有效采样时按零提前处理。Mac 脚本实发前预演七次按键准备，将耗时中位数的整数毫秒加到正的网络提前量上，自动部分封顶 15 毫秒。
- **额外提前量**。`--extra-lead-ms` 加在正的自动提前量之上。例如自动提前 13 毫秒、额外提前 120 毫秒，计划就在目标前 133 毫秒投递回车。
- **实际提前量**。日志中「本机投递回车按下」记录系统投递调用完成的本机时间。接收端显示的分钟、服务器接收时刻和排队顺序需要各自的观测数据。

#### 一台 Mac 的实测记录

用平均 RTT 模式定向发送到测试账号，每轮核对 **发送方 iPhone 微信会话列表**中的消息预览和右侧分钟。下表只计入已核对的轮次。换设备或网络后，请用自己的测试会话重新校准。

| 额外提前量 | 显示目标分钟 | 显示上一分钟 |
|---:|---:|---:|
| 90 ms | 3 | 0 |
| 120 ms | 2 | 0 |
| 135 ms | 0 | 2 |
| 140 ms | 1 | 0 |
| 145 ms | 1 | 0 |
| 170 ms | 0 | 1 |
| 200 ms | 0 | 1 |

135 毫秒的两轮实际分别提前 137.8 和 136.5 毫秒，均落在上一分钟。140 毫秒另有一轮已投递，但未核对列表分钟。各档样本有限，120 毫秒是这台测试机的参考设置。

若希望在正的自动提前量上再提前 5 毫秒，可运行 `./auto_enter.py -n --wechat-rtt --extra-lead-ms 5`。这 5 毫秒加在默认上限之后，仅本次生效。

要只验证倒计时和触发时刻，可运行 `./auto_enter.py -n --wechat-rtt --dry-run`。模拟运行无需按键权限。

Mac 上的命令行脚本会分别记录回车按下和释放投递给系统的时间，以及距目标还剩多少毫秒。正数表示提前。服务器实际接收时刻需要服务端时间戳才能验证。若希望固定提前 100 毫秒，可用 `./auto_enter.py -n -l 100`。
